Google Cloud 설정 방법
  1. Google Cloud Console에서 프로젝트를 만들고 Google Calendar API를 사용 설정합니다.
  2. Google Auth Platform에서 브랜딩(앱 이름: 언제봐?), 대상(외부), 연락처를 설정합니다. 테스트 중에는 사용할 구글 계정을 테스트 사용자로 추가합니다.
  3. 데이터 액세스에 calendar.calendarlist.readonly, calendar.events.readonly 범위를 추가합니다.
  4. 클라이언트 → 클라이언트 만들기 → 웹 애플리케이션을 선택합니다. 승인된 JavaScript 원본에 https://pickatime-phi.vercel.app을 등록합니다. 리디렉션 URI나 클라이언트 보안 비밀은 사용하지 않습니다.
  5. 발급한 클라이언트 ID를 위 입력칸에 저장하고 Chrome 또는 Safari에서 연결을 테스트합니다.
  6. 모든 사용자에게 공개하려면 Google의 게시·민감한 권한 검증 절차를 완료합니다. 테스트 모드에서는 등록한 테스트 사용자만 연결할 수 있습니다.
